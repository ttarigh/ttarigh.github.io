# Tina Tarighian's Portfolio

This repository contains the source code for my portfolio website, hosted on GitHub Pages at [ttarigh.github.io](https://ttarigh.github.io) and accessible through [tina.zone](https://tina.zone).

## 🎯 What's New

This website has been completely cleaned up and modernized:
- ✅ **Responsive Design**: Works perfectly on all screen sizes
- ✅ **Performance Optimized**: Combined CSS/JS files, removed bloat
- ✅ **No Build System**: Pure static HTML for easy maintenance
- ✅ **Modern Code**: Vanilla JavaScript, no jQuery dependencies
- ✅ **GitHub Pages Ready**: Simple deployment setup

## 📁 Repository Structure

- `index.html` - Main responsive splash page
- `mobile-splash.html` - Cheeky mobile permission page
- `mobile-main.html` - Mobile-optimized splash page
- `art.html` - Art projects (table layout)
- `work.html` - Work projects (grid layout)
- `about.html` - About page
- `css/main.css` - Combined stylesheet
- `js/main.js` - Combined JavaScript
- `images/` - Project images organized by category
- `splash/` - Splash page images

## 🚀 Deployment

This site is deployed on GitHub Pages. To deploy:

1. Push changes to the `main` branch
2. GitHub Pages will automatically build and deploy
3. Site will be available at `https://ttarigh.github.io`

## 🎨 Design Features

- **Responsive Splash Page**: Scales perfectly on all devices
- **Interactive Hover Effects**: Hand/bunny animations with color changes
- **Mobile-First**: Dedicated mobile experience with permission flow
- **Clean Typography**: Consistent Arial font throughout
- **Performance Optimized**: Fast loading with minimal HTTP requests

## 🛠️ Development

To run this site locally:

```bash
# Using Python 3
python3 -m http.server 8000

# Or using Node.js
npx serve

# Or using any local server
```

Then visit `http://localhost:8000` in your browser.

## 📱 Mobile Experience

The site includes a unique mobile experience:
1. Mobile users see a permission page first
2. After agreeing, they see a mobile-optimized splash
3. All pages are fully responsive
